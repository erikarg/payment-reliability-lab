# Bundled typefaces

Both files are served from this repository rather than fetched at build time, so
the build has no network dependency and behaves the same offline.

| File | Family | Licence |
| --- | --- | --- |
| `jetbrains-mono.woff2` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |
| `inter.woff2` | [Inter](https://github.com/rsms/inter) | SIL Open Font License 1.1 |

Each is the variable Latin subset. The OFL permits bundling and redistribution
with this kind of attribution; neither font is modified.
